DATE FORMAT POLICY
==================
Project display / manual entry / CSV text / XLSX text: DD/MON/YYYY
Example: 01/Sep/2026
Excel real-date cells: display them as dd/mmm/yyyy
MySQL DATE storage: YYYY-MM-DD

Conversion examples:
01/Sep/2026 -> 2026-09-01
25/Sep/2026 -> 2026-09-25
09/Feb/2026 -> 2026-02-09

Months: Jan, Feb, Mar, Apr, May, Jun, Jul, Aug, Sep, Oct, Nov, Dec.
