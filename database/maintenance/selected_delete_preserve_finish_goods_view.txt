SELECTED RECORD DELETE - VIEW PRESERVATION
==========================================
After Super Admin deletes selected Finish Goods records, the system returns to the same table context.

Preserved state:
- selected Division
- Search text
- Grade filter
- Sort column/direction
- Rows per page (25/50/100)
- Current page

If deletion reduces the number of available pages, the existing table logic automatically clamps the requested page to the last valid page.
